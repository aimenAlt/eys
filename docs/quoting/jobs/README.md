# Job notes (git-ignored)

One file per job: `<yyyy-mm>-<customer-first-name>-<scope>.md`, e.g. `2026-10-maria-vanity.md`.

Each file is the working note from master guide section 6.2: job identity and tabs, intake and photo findings, takeoff, assumptions, SimplyWise question log, raw estimate, research, audit, pricing, the complete entry package, extra lookups, final verification, and later any actuals or won/lost outcome.

Everything in this folder except this README and `.gitignore` is ignored by git, so customer details stay on this machine and never reach GitHub.
